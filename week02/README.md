# KERT 웹 백엔드 스터디 - 2주차

## 실행 방법
1. week02로 이동
```bash
cd week02
```
2. 서버를 실행
```bash
node app.js
```
3. 브라우저에서 접속(아래 링크 복사, 붙여넣기)
http://localhost:3000/posts

## 구현한 라우트
1. get /
게시글 목록 페이지 /posts로 이동
-> 처음 사이트 접속하면 게시글 목록부터 쉽게 볼 수 있다.

2. get /posts
저장된 게시글 목록을 화면에 표시
list.ejs에 게시글 데이터를 전달-> 제목, 작성자를 함께 띄움.
검색어 -> 제목에 검색어가 포함된 게시글만 표시하도록 함.

3. get /posts/new
새 게시글을 작성할 수 있는 입력창(제목/작성자/내용 입력->등록 버튼)

4. post /posts
입력한 제목/작성자/내용 받아서 새 게시글 등록
제목이 비어 있거나 공백만 있는 경우->등록X
등록되면 새 게시글 상세 페이지로
게시글 id는 기존 게시글 중 가장 큰 id+1(id 중복 안됨.)

5. get /posts/:id
url에 포함된 게시글 id로 게시글 찾기->표시
게시글이 존재하면 제목/작성자/내용이 뜨지만 없으면 코드 404와 오류 페이지

6. post /posts/:id/delete
url에 표함된 게시글 id로 삭제
삭제 작업이 끝나면 /posts로

7. 등록 안 된 주소가 들어오면 404, 오류 페이지
