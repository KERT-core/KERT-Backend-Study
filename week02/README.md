# KERT 웹 백엔드 스터디 - 2주차 (EJS 게시판)

## 실행 방법
1. 프로젝트 폴더로 이동: `cd week02`
2. 패키지 설치: `npm install`
3. 서버 실행: `node app.js` (또는 `npm run dev`)

## 구현한 라우트 및 기능
- `GET /posts`: 게시글 목록 조회 (도전 과제: 키워드 검색 기능 포함)
- `GET /posts/new`: 게시글 작성 폼 화면
- `POST /posts`: 게시글 작성 및 저장 (도전 과제: 빈 제목 방지 처리)
- `GET /posts/:id`: 게시글 상세 조회 (도전 과제: 없는 게시글 접속 시 404 처리)
- `POST /posts/:id/delete`: 게시글 삭제
- `404 Handler`: 존재하지 않는 경로 접속 시 커스텀 404 페이지 렌더링

## 구현한 도전 과제
1. 검색 기능 (`/posts?keyword=...`): 제목에 검색어가 들어간 글만 필터링하여 출력
2. 빈 제목 방지: 제목이 입력되지 않은 경우 저장하지 않고 400 응답 처리
3. 나만의 404 페이지: 없는 주소나 없는 게시글 요청 시 `views/404.ejs` 렌더링
