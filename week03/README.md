# KERT 웹 백엔드 스터디 - 3주차

Express와 Ejs를 사용한 게시판에서 회원 인증, 권한 관리 기능을 추가하였다.
bcrypt를 이용한 비밀번호 해시 처리, 로그인 여부에 따른 페이지 접근 제한, 관리자 권한 사용하여 회원 관리 등을 사용했다.

## 실행 방법

1. git clone, week03으로 이동, 패키지 설치
2. 서버 실행 방법 : node app.js
3. https://localhost:3000

## 관리자 계정 만드는 법

서버 실행 후 회원가입 페이지(/signup)에서 계정 생성한다.(회원가입 버튼 있음.)
로그인 페이지(/login)에서 회원가입한 아이디, 비밀번호로 로그인한다.

node make-admin.js (아이디)
-> 해당 계정에 관리자 권한이 부여된다.
로그아웃한 뒤 관리자 계정으로 다시 로그인,
관리자 페이지(/admin)에 접속한다.


## 구현한 라우트

- get, post /signup : 회원가입 페이지 및 처리
아이디 및 비밀번호 입력받아 회원가입처리
아이디 중복 확인 후 비밀번호를 bcrypt로 해시 후 저장한다.

- get, post /login : 로그인 페이지 및 처리
아이디 및 비밀번호 입력받고 bcrypt 사용하여 가입된 회원이면 로그인 처리
- post /logout : 로그아웃 처리

- get /posts : 게시글 목록(조회)
- get /posts/new : 게시글 작성(제목 및 내용, 로그인 사용자만)
- post /posts : 게시글 작성 처리 (로그인 사용자만)
- get /posts/:id : 게시글 상세 조회
- post /posts/:id/comments : 댓글 작성 (로그인 사용자만)
로그인 사용자의 댓글을 db에 저장까지 한다.

- get /admin : 회원 목록 조회(관리자)
- post /admin/users/:id/role : 회원 권한 변경 (관리자)

- get /my : 본인이 작성한 게시글만 모아보기(로그인 사용자만)
